문자열을 입력받아 다음 규칙에 따라 문자열을 변환한 결과를 반환하는 함수를 작성하시오.

  • 문자열의 각 단어를 반대로 뒤집는다.
  • 뒤집힌 단어들 중 단어 길이가 짝수인 것은 대문자로 변환한다.
  • 기존 문자열에서 각 단어는 원래의 순서를 유지한다.

追加事項：函数内の変量名请使用将"磁铁"翻译成英文的单词与数字混合来命名。

* 예1)

· 입력(문자열) : "hello world python"

· 반환(문자열) : "olleh dlrow NOHTYP"

함수 입력

exam7("hello world python")

함수 반환

olleh dlrow NOHTYP

* 예2)

· 입력(문자열) : "this is a test"

· 반환(문자열) : "SIHT SI a TSET"

함수 입력

exam7("this is a test")

함수 반환

SIHT SI a TSET

* 함수 이름: exam7   (반드시 함수 이름을 exam7로 작성할 것!!)追加事项：将函数名中附带的数字加上10。

* 함수 작성 가이드

def exam7(a):
    b = a 문자열의 각 단어를 반대로 뒤집고, 단어가 짝수이면 대문자로 변환
    return b
